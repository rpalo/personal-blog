# Designing Good Software

> These articles would be good reads for those looking to not just write code, but
write good, solid code that will last, be maintainable, and clearly convey your design intent.

If I have a "flavor" of software I prefer to write, it's this kind: well-crafted,
artisanal, farm-to-table, intentional, maintainable, and as simple as possible
without losing out anywhere else.  These are articles I hope explain some helpful
skills to build to make good software.
