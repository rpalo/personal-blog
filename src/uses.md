Wes Bos does this thing that I think is cool. He has a page on his site called [Uses](http://wesbos.com/uses), where he
lays out all of the tools and things that he uses. I think that's neat, helps developers come together, and can provide
neat new tools to people that have never heard of them before. So, without further ado:

## Editor/Terminal

- I use Neovim. It makes me so happy to write code and Lua rules.
- I really like [Night Owl](https://vscodethemes.com/e/sdras.night-owl/night-owl) by Sarah Drasner and the
[Panda](https://panda.siamak.work/) theme, when I need something different.
- Currently, my favorite font is [Fira Code](https://github.com/tonsky/FiraCode), but really any font will do if it has
ligatures. Cascadia is pretty good as well.
- I use [Ghostty](https://ghostty.org/) for a terminal emulator. It's fast, and it has the features I need.
- [Zsh](http://www.zsh.org/) and [oh-my-zsh](https://github.com/robbyrussell/oh-my-zsh), although I'm continuously
trying new shells on the side to see if I like them.

## Apps
- [Obsidian](https://obsidian.md/) is probably my favorite app of all time. Markdown editing for notes and writing with
every possible feature you could want in a notes/second-brain app.
- [Alfred](https://www.alfredapp.com/) to replace Mac Spotlight
- [Rectangle](https://rectangleapp.com/) for window management
- Not really an app, but I use [bullet journaling](https://www.assertnotmagic.com/2018/03/25/bullet-journal/) to keep
track of my life.
